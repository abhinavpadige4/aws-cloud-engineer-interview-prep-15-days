# AWS Cloud Engineer Interview Preparation - 15 Day Plan

## Overview
This comprehensive 15-day study plan is designed to prepare you for an AWS Cloud Engineer interview, covering all essential AWS services: EC2, S3, VPC, IAM, Lambda, RDS, CloudFormation, and CloudWatch.

## Daily Structure
Each day includes:
- **Study** (60 min): Documentation review and concept learning
- **Practice** (30 min): Multiple-choice questions and scenario-based problems
- **Hands-on** (60 min): Practical exercises using AWS CLI, Console, or Infrastructure as Code
- **GitHub** (15 min): Documenting progress, adding notes, scripts, and solutions

## Services Covered
- **Day 1-2**: EC2 (Elastic Compute Cloud)
- **Day 3-4**: S3 (Simple Storage Service)
- **Day 5-6**: VPC (Virtual Private Cloud)
- **Day 7-8**: IAM (Identity and Access Management)
- **Day 9-10**: Lambda (Serverless Computing)
- **Day 11-12**: RDS (Relational Database Service)
- **Day 13-14**: CloudFormation & CloudWatch
- **Day 15**: Review, Practice Exam, and Final Preparation

## Getting Started
1. Ensure you have an [AWS Free Tier account](https://aws.amazon.com/free/)
2. Install and configure [AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html)
3. Clone this repository: `git clone https://github.com/abhinavpadige4/aws-cloud-engineer-interview-prep-15-days.git`
4. Follow the daily schedule starting from Day 1

## Daily Schedule Template
```
Day X: [Topic]
```
